# 🤖 Projetos de Inteligência Artificial

Repositório com projetos práticos de Machine Learning e IA desenvolvidos durante a formação técnica em Inteligência Artificial e a graduação em Ciência da Computação na FECAP.

---

## 📁 Projetos

### 🌱 Startup AGI — Sistema de Recomendação de Culturas Agrícolas
**Arquivo:** `[Projeto_Startup_AGI.ipynb](https://github.com/alexsander020/AGI)`

Projeto completo de Machine Learning aplicado ao agronegócio. A partir de um dataset real com variáveis como pH do solo, temperatura, umidade e pluviosidade, o modelo recomenda qual cultura plantar para maximizar a produtividade.

**Etapas do projeto:**
- Análise exploratória dos dados (EDA)
- Pré-processamento e tratamento de dados ausentes
- Treinamento e comparação de modelos de classificação
- Avaliação de desempenho com métricas de acurácia

**Tecnologias:** Python · scikit-learn · pandas · matplotlib

---

### 🌳 Random Forest — Exercícios Práticos
**Arquivo:** `Random_Forest_Exercicios_Alexsander.ipynb`

Implementação e análise do algoritmo Random Forest, explorando hiperparâmetros, importância de features e comparação com outros modelos ensemble.

**Tecnologias:** Python · scikit-learn · pandas

---

### 🧠 Redes Neurais
**Arquivo:** `Redes_Neurais.ipynb`

Construção e treinamento de redes neurais artificiais, cobrindo arquitetura de camadas, funções de ativação e processo de backpropagation.

**Tecnologias:** Python · scikit-learn / TensorFlow

---

### 🔧 Pré-processamento de Dados
**Arquivo:** `Pre_processamento_de_dados01.ipynb`

Técnicas essenciais de preparação de dados para modelos de ML: normalização, codificação de variáveis categóricas, tratamento de outliers e divisão treino/teste.

**Tecnologias:** Python · pandas · scikit-learn

## ▶️ Como executar

**Pré-requisitos:** Python 3.8+ e Jupyter Notebook instalados.

```bash
# Clone o repositório
git clone https://github.com/alexsander020/Projetos-de-IA.git
cd Projetos-de-IA

# Instale as dependências
pip install pandas numpy scikit-learn matplotlib seaborn jupyter

# Abra o Jupyter
jupyter notebook
```
